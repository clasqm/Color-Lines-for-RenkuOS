Colorlines
=======================

**Description:** QT implementation of colorlines

[![colorlines.png](https://i.postimg.cc/x8DMfJ7Z/colorlines.png)](https://postimg.cc/0MnbZQ9G)

Click on a circle and click again where you want to place it. Get five or more in a line (horizontal, vertical or diagonal) to make them disappear.

Adapted and packaged for Haiku by Michel Clasquin-Johnson. Tested on Haiku R1/beta 5 in the x86_64 bit variant.

**Requires:** QT5  
**Original Source:**  https://github.com/alexander-a-kladov/color_lines
